# Blasting Maces<!--$headerTitle--><!--$pmc:delete-->

Why break one block when you can break nine? Now maces hit harder than ever!<!--$pmc:headerSize-->

### Features
Adds a new enchantment, Blasting, that Maces can be enchanted with to break multiple blocks at once.
- Hold right click to charge a blast, then release while aiming at a block to break a 3x3 area.
- The more a single blast breaks, the faster it will wear down, so keep an eye on its durability.
